# Plant Data Logger (demo)

Interactive demo of a plant data logger for water treatment: process values from the PLCs into PostgreSQL, live trends, alarms, network-drop buffering and daily reports. Two sample units: an MSF desalination unit and an acid dosing skid. English and Arabic.

Everything runs in the browser on simulated values. There is no PLC connection, no database and no backend code in this repository.

Static site: `index.html`, `styles.css`, `app.js`, Chart.js in `lib/`. Deploy as-is (Vercel, framework "Other").
